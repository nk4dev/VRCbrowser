VRCbrowser デモワールド

VRChat ワールドの中で Web ページを表示するビューアです

デモページ

「よく使うサイト」メニューから開けます。

文字と CSS
色、大きさ、行間、中央寄せの段組み、背景ボックス、カスタムプロパティ、@media
リストと要素
入れ子のリスト、番号の種類、引用、ルビ、フォーム部品、文字参照
JavaScript
時計、DOM の書き換え、ループで作る表
Markdown
HTML ではないテキストは Markdown として表示します
画像
.png / .jpg の URL は画像として表示します

操作

  • URL 欄 … 好きな URL を入力して開きます
  • 戻る / ホーム / 更新 … 履歴を戻る、このページへ戻る、読み込み直す
  • 表示中のページは、インスタンスにいる全員に同期されます

ページ内のリンクは開けません(Udon は実行時に URL を作れないため)。読み込みは約 5 秒に 1 回までです。
