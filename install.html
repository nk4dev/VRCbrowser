VRCbrowser を VCC に追加

VRChat ワールド用のインワールド・ページビューアです。Add the VRCbrowser package listing to VCC or ALCOM.

ワンクリックで追加

VCC / ALCOM に追加

VRChat Creator Companion または ALCOM が開き、リポジトリの追加を確認する画面が出ます。Opens VCC or ALCOM and asks to add the repository.

開かない場合(手動で追加)

https://raw.githubusercontent.com/nk4dev/VRCbrowser/main/index.json
  1. VCC の Settings → Packages → Add Repository を開きます(ALCOM は「パッケージ」→「リポジトリを追加」)。
  2. 上の URL を貼り付けて追加します。
  3. プロジェクトの管理画面で VRCbrowser を追加します。
